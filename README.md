# Posterizarr Cinematic Overlays

A collection of custom cinematic overlays for Posterizarr, designed to give your media library a clean, cohesive look.

## Included overlays

- **4K DV** — 4K Dolby Vision
- **4K HDR** — 4K HDR
- **4K HDR10+** — 4K HDR10+
- **4K SDR** — 4K SDR
- **HD** — High Definition
- **IMAX** — IMAX

## Installation

1. Download the overlay PNG files from this repository.
2. Back up your existing Posterizarr overlay files.
3. Copy the selected overlays into your Posterizarr overlay directory.
4. Configure Posterizarr to use the corresponding overlay filenames.

## Note
- IMAX overlay will need to be added manually to any poster you wish in order to show in Library.

Check your Posterizarr configuration and documentation for the correct paths and overlay settings.
